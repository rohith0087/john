# IDN Watch diagram style

Source: the existing IDN Watch local UI and the user's established direction for a familiar sales interface.

| Role | Value |
|---|---|
| Paper | #ffffff |
| Secondary paper | #f5f6f8 |
| Ink | #132b47 |
| Muted | #526579 |
| Soft / connectors | #61758b |
| Border | #b8c5d2 |
| Accent | #0f6cbd |
| Accent tint | #eff6fc |
| All human-facing typography | Segoe UI, Arial, sans-serif |
| Font source | system; no network requests |

The local Diagram Design skill supplied the HTML/SVG workflow, accessible figure structure, connector rules, and verification helpers. This artifact reuses the project's established palette rather than changing the shared skill's installed style guide or creating a global style profile. Content is drawn from the current prototype behavior, not a production architecture or future automation promise.
